## 1. データフロー名

- データフロー名称: CreateTrainingDataSet
- NiFi JSONファイル: CreateTrainingDataSet.json
- バージョン: 1.0
- 改版日: 2026-03-30
- ライセンス： MIT License


## 2. データフローの概要

- 図面（画像ファイル）と対になる図面デジタイズ支援システムのデジタイズ結果出力ファイル（ジオメトリ）を用いて、AI学習用のデータセットを作成する。
- 当データフローは２つに分かれており、図面とジオメトリをインプットとする学習データ作成のデータフローと、蓄積した学習データをインプットとする学習データセット作成のデータフローで構成される。


## 3.1. 学習データ作成データフローの入出力仕様
インプットデータ（ParameterContext：InputPath)
以下の２つのデータをInputPathで指定するディレクトリへ格納する。
- 対象図面の画像ファイル。
- 対象図面のデジタイズ結果(線データ)を持つGeoJSON。当データフローのファイルの命名規則は『【画像ファイル名（拡張子除く）】.json』。

アウトプットデータ（ParameterContext：RootPath)
- 対象図面の画像ファイル（学習元画像）と、デジタイズ結果から作成した画像ファイル（学習元正解画像）の２つ（学習データ）をRootPathで指定するフォルダ内に格納する。

特記事項
- 一度処理対象となったインプットデータはデータフロー側でタイムスタンプを保持しているため、再実行する際はデータフローのタイムスタンプをクリアするか、別名で実行する必要がある。


## 3.2. 学習データセット作成データフローの入出力仕様
インプットデータ（ParameterContext：RootPath、MakeDatasetDir、MakeDatasetStartFilename)
- RootPath：複数の学習データを格納したフォルダ。学習データ作成データフローのアウトプットデータ。
- MakeDatasetDir：学習データセット作成データフローの出力フォルダに、実行トリガーファイルを格納する。
- MakeDatasetStartFilename：学習データセットの実行トリガーファイル名。データフローの実行直後にこのファイルは削除される。ファイルの内容は問わない。

アウトプットデータ（ParameterContext：MakeDatasetDir)
- RootPathにある学習データに基づいて学習データセットを作成し、MakeDataSetDirで指定するフォルダへ格納する。
